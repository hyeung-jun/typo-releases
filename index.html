How it works

Less structure to maintain, more time typing.

One canvas per note
There are no sections and no nested pages. A note is a single surface you scroll and keep adding to. Headings become an outline in the margin when you want to jump, and stay out of the way when you don't.
Plain markdown files
Every note is a .md file in a folder you picked. Open it in any other editor, grep it, back it up however you already do. Pasted images sit next to it in an assets folder.
Git is the sync
Point the folder at a remote and Typo commits and pulls for you, using the git and credentials already on your machine. No server of ours, no account, nothing to trust but your own repo.
Blocks, not a form
Type / for headings, lists, checkboxes, quotes and tables. Drag blocks to reorder them, paste an image and drag its corner to resize. Nothing that markdown can't hold is in the menu.
Paper and ink
Two themes, light and dark, with no accent colour in either. What is active is darker or heavier, never bluer.

The title lives in the front-matter, not the filename. Renaming a note is an edit to its content, so git sees one change rather than a delete and a create.

The filename is a UUID. It never changes and never contains a space, which is also why image names are UUIDs: a markdown image URL ends at the first space.

An image's width rides along as ?w=320. Markdown has no way to say how wide a picture is, so the resize is folded into the URL and unfolded on read. Any other viewer just ignores it.

Hand-arranged order is a file too, .typo-order, kept in the vault so it travels with the notes.

The name and the mark

Named after the typewriter, for the typing.

64 px
32 px
22 px

Typo is the front of typewriter, and what it points at is typing. It was not chosen for a meaning. It was chosen for being short, and a little cute, and easy to say.

It does not mean a mistake. The dictionary gives that sense first, and at one point it nearly decided something: a proposal to knock one key out of line, so the icon would say "typo" too. It was dropped, because the name is about the act, not the error. Everything else in the app leans the same way. One page with no folders to file into, a title kept out of the filename, a menu with nothing markdown can't hold. The less structure there is to maintain, the more of what is left is typing.

The mark is a typewriter reduced to its keys. Eight discs in three rows: three, three and two. A whole typewriter drawn small is a silhouette of carriage and platen that collapses into a lump at icon sizes. The keys are the part a writer touches, and they are the part that survives being shrunk.

The rows sit tighter than the columns, about 0.85 of the pitch, and that ratio is the whole drawing. Square it up and it stops being a keyboard and becomes a keypad, a dice face, a drag handle. The bottom pair is offset by exactly half a column, the way a machine's keys stagger and a grid's cells do not. That taper also gives the mark a bottom edge, and so a way up.

Discs have no inside to lose, so eight of them still read as eight at 32 pixels. There is one colour, ink on paper, with no accent. In the app an accent marks what is active, and an icon is never active.

Typo is not yet signed, so both systems stop it the first time. On macOS, after the refusal go to System Settings → Privacy & Security, scroll to the bottom and click Open Anyway (on macOS 14 and earlier, right-click the app and choose Open instead). On Windows, when SmartScreen stops the installer, click More info, then Run anyway. After that it launches normally.

  1. On macOS, open the .dmg and drag Typo into Applications. On Windows, run the .msi.
  2. Launch it and pick a folder, ideally an empty one. Other files already in it stay where they are, but Typo does not list them.
  3. That is all it takes to write. To keep the notes on more than one computer, set up sync.

Sync

Keep your notes on every computer.

Typo syncs through a private GitHub repository that only you can see. It uses the git program on your computer and the GitHub sign-in you give it once, so Typo never asks for or keeps a password. The setup is a few minutes in the Terminal (Command Prompt on Windows), once per computer.

  1. Install git. On macOS, open Terminal and run xcode-select --install, then click Install in the window that appears. On Windows, install Git for Windows with its default options.
  2. Install the GitHub CLI from cli.github.com. This is the small tool that signs your computer in to GitHub.
  3. Sign in once. Run gh auth login and answer GitHub.com, HTTPS, Yes, and Login with a web browser. Copy the code it shows, press Enter, and approve it in the browser. Then run gh auth setup-git. Restart Typo afterwards.
  4. Make a repository at github.com/new. Give it any name, choose Private, and leave "Add a README" off, since any markdown in it would show up as a note. Copy its address, which looks like https://github.com/you/notes.git.
  5. Connect it in Typo. At the bottom of the sidebar, click Set up git sync, then the git icon beside the folder name. Paste the address and click Connect. From then on Typo commits and syncs by itself.
  6. On another computer, do steps 1 to 3, pick an empty folder in Typo, and connect the same address. Your notes arrive with the first sync.

If Typo says this machine has no credentials for the remote, step 3 has not been done on this computer yet. If it says there is no repo at that address, check the address, and that you signed in with the account that owns the repository. Already use git with an SSH key? A git@github.com:you/notes.git address works too, and steps 2 and 3 can be skipped.

Questions

Before you download.

Is Typo free?
Yes. There is no account, no subscription and no server of ours. The installers are on GitHub Releases. The source code is not public for now.
How is it different from Obsidian?
Both keep notes as markdown files in a folder you own. Typo does less on purpose: no plugins, no nested folders, no graph of links. Each note is one canvas, and sync is built in, running on a git repository of your own.
Can it open the markdown I already have?
Not yet. Typo lists only the notes it made, whose files are named by a UUID. Other files in the folder are left alone, so a README or an existing set of notes can share the repository without being touched.
Does it work offline?
Yes. Notes are files on your disk, so writing and saving never need a network. Only sync does.
Do I need GitHub?
Only for sync, and not even then: any git remote you can push to works. The guide above uses a private GitHub repository because it is the shortest path. Without a remote, Typo is a local notes app.
Which systems does it run on?
macOS 13 or later on Apple silicon, and Windows 10 or later. There is no Linux, iPhone or Android version.
