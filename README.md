# Typo releases

Installers for Typo, a desktop notes app that keeps each note as a plain
markdown file in a folder you choose and syncs it with git.

See [the Typo page](https://hyeung-jun.github.io/typo-releases/) for what it
is and how it works, or download the latest version from [Releases](https://github.com/hyeung-jun/typo-releases/releases/latest).
The source code is kept private; this repository only hosts the builds.

Typo is free to use, including commercially, and the installers may be
redistributed unmodified; see [the terms of use](TERMS.md). The licences of the
open-source software it includes are in `THIRD_PARTY_NOTICES.md`, attached to
every release.
